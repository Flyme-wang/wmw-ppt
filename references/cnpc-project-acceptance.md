# 中石油项目结题验收汇报

适用于按项目方模板汇报油气地质、储层地质力学和数值模拟成果。这里记录的是一套经项目汇报使用的做法。具体配色、标识、页眉页脚沿用本次指定母版。

## 用五个问题组织汇报

| 汇报顺序 | 要回答的问题 | 适合展示的材料 |
|---|---|---|
| 研究内容 | 项目要解释哪个地质现象，交付什么成果？ | 一张井震解释剖面或研究区图，标出研究对象和待解释现象 |
| 技术路线 | 怎样从实测资料走到可检验的模拟结果？ | 用流程图连起观测约束、模型假设、分期模拟、可对比的输出和检验资料 |
| 主要模拟工作与认识 | 各阶段发生了什么，哪些证据支持对其成因的解释？ | 按地质事件排结果图。构造演化可按“拉张成槽与早期充填—后续充填与埋藏剥蚀—差异沉积与固结”展开。期次据研究对象确定，模型编号放图注或备注 |
| 现场应用与资料验证 | 哪些认识与观测吻合，哪些仍有偏差？对开发有何意义？ | 对照地震层位、井厚、实测压力或地形。分别写明已发生的现场应用和仍待验证的工程建议 |
| 结论与建议 | 哪几条认识有证据，下一步据此做什么？ | 一条结论对应前文一幅图或一项量值，建议写清对象和用途 |

优先复用已验收报告、原始结果图和关键帧。模型的预设几何、位移引导、沉积厚度等会影响解释时，在相关页写明。若跨阶段更换基底、网格或重建参考态，在接续处注明继承了哪些几何或物理量，避免动画的视觉连续暗示全部力学历史也连续。

## 一页让听众看清一个变化

- **页标题写认识。** 上部用 2–3 行说明“图中哪里发生了什么变化”和“这一变化支持什么认识”。优先给位置、阶段、厚度或量级，删去重复图例的文字。
- **每幅图有独立图题。** 紧贴图的正上方写清对象、期次及对比量。图表置于页面下部，充分利用页宽。沿用模板的标题色、标识和页码，正文默认黑色。中文及图内中文使用微软雅黑，英文、数字和单位使用 Times New Roman。
- **让问题决定分页。** 例如展示差异沉积时，第一页用同一里程的早晚剖面回答“新层在哪里增厚”，第二页追踪同一老层界面回答“上覆载荷对应什么升降”。长剖面优先整宽单图或同宽上下对照。并排后槽肩、尖灭点或轴标难以辨认，就拆页；把主图放大，同时给图题、坐标、图例和页脚留足空间。

## 所有图片等比，剖面还要保真

1. **先检查原图。** 同一对比组核对里程范围、高程或深度基准、单位、横纵显示比例及纵向放大倍数。源图有纵向放大时沿用并标明；局部放大图注明范围与比例。多联图即使整张图片等比，内部的剖面也可能已被挤窄。遇此情况，取归档单幅图或原始坐标，按原坐标跨度和绘图区宽高比重绘。
2. **再检查 PPT 对象。** 所有照片、剖面、云图、标识和动画封面均以同一比例缩放宽高并锁定比例。用源图宽高比核对最终放映的有效宽高比，包含外层组合缩放。适配版心时保留轴标、图例、色标和单位，可将多图拆开；避免拉伸填框或裁掉有效数据。动画和静态关键帧沿用相同地层配色、坐标和基底显示范围。
3. **按实际放映尺寸复查。** 对照归档单图查看槽坡、层厚和尖灭点是否变形，逐页读轴标和图例。分页后复查页码、图题、放映链接和动画首帧。交付改版时保留上一版；需要比较排版时，附原页与拆分页的放映截图。

## 验证写到资料能支持的程度

同线同基准的井震资料可按层位或井点报告偏差，注明单位、位置和样本范围。区域参考线可另图展示起伏趋势，注明线路或高程基准差异；参与校准的数据注明其用途。文献认识在正文用“（第一作者，年份）”，引用原图标注原图号，改绘注明“据……改绘”。备注记录可回查的数据、结果帧或文献出处。播放演化动画时，同时保留能独立说明结论的静态关键帧。
