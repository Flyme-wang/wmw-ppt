# wmw-ppt — 学术级科学 PPT 生成 Skill

生成出版级学术 PPT 的 Qoder Skill，专为**数值模拟（FEA/FDM/DEM）多模型对比分析**设计。

## 设计哲学

- **极简克制**：干净的学术版式，拒绝花哨装饰、渐变与卡通元素
- **图表为王**：图表是 PPT 的核心视觉，文字为图表服务
- **一页一观点**：每页只传递一个核心结论
- **留白呼吸**：页面四周预留充足空白

## 核心规范（MANDATORY）

| 规范 | 要求 |
|------|------|
| 统一 Colorbar | 多模型/多工况对比时，同一变量必须使用完全相同的 colorbar 范围（以最极端工况为基准，向上取整） |
| 图片等比例缩放 | 所有截图/图表保持原始宽高比，PIL 计算等比缩放居中放置，禁止拉伸变形 |
| 最小字号 18pt | 正文/要点/图注 ≥ 18pt；页面标题 20pt；仅密集表格（13–14pt）与页码例外 |
| 表格垂直居中 | 表格单元格文字必须水平居中 + 上下垂直居中（`cell.vertical_anchor = MSO_ANCHOR.MIDDLE`） |
| 版本号最前 | 交付文件命名版本信息放文件名最前：`v1_主题.pptx`、`v2_主题.docx`，禁止后缀式 `主题_v2.pptx` |
| 图注详细 | 每张图注释 = 模型名 + 关键数值 + 结论解读 |
| 标题即结论 | 页面标题直抒结论（≤15 字），禁止空洞宽泛标题 |
| 结果分析深度 | 必须包含参数差异→结果差异定量对照（变化百分比 vs 基准）与逐模型机理分析页 |

## 工作流

1. **提取 ODB 数据** — Abaqus ODB 扫描各变量极值（S/PE/PEEQ/U/POR/DAMAGE/AC YIELD）
2. **统一 Colorbar** — 扫描所有模型后，以最极端模型为基准统一范围（注意积分点值与节点外推值的差异）
3. **截取云图** — wei204 view 插件标准化视角（ASCII 路径、Viewport: 1）
4. **生成图表** — matplotlib 柱状图 / 雷达图 / 变化率横向条形图
5. **组装 PPT** — python-pptx 16:9，标准 18 页结构（封面→模型概述→云图→定量图表→机理分析→结论）
6. **验证** — 页数、图片路径、字体、表格垂直居中

## 使用方式

在 Qoder IDE 中通过 `/wmw-ppt` 调用，或直接描述任务（如"分析 6 个敏感性模型结果，制作对比 PPT"）。

## 依赖

- `python-pptx` ≥ 0.6.21
- `matplotlib` ≥ 3.5
- `Pillow`（PIL）
- `numpy`
- Abaqus MCP（ODB 数据访问与截图）

## 典型应用

- 水力压裂多参数敏感性分析（渗透率 / 泄漏 / 流量 / 网格尺寸 / 断裂能）
- 多工况 FEA 结果对比（应力 / 应变 / 损伤 / 位移 / 孔压）
- 多模型机制对比与工程建议汇报
